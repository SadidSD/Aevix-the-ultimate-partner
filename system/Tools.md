# Aevix Tool Reference

## Task Management
- **readTasksFromFile**: Reads JSON from .md files.
- **writeTasksToFile**: Writes JSON to .md files.
- **isMetaTask**: Code-level filter for 'silly' or administrative tasks.

## System Locks
- **Onboarding Shield**: Physical lock (OpeningFunction.md) preventing extraction.
- **Triple-Lock Hardware**: Flag + FactCount + Keyword check (Occupation, Goal).
